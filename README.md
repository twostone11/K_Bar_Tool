# K_Bar_Tool

凭记忆画K线的白板。先用其他看图软件记住一段走势，再在这里把它画出来。

技术方案见 [docs/design.md](docs/design.md)。当前只实现了白板绘图，没有出题、数据和评分。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查并打包
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 在某一列按下并上下拖动 | 画一根K线，起点为开盘价，终点为收盘价，最高、最低价先与实体相同 |
| 拖动K线上的圆点 | 调整最高价、最低价、开盘价、收盘价 |
| 在已有K线上单击 | 不改动该K线；在已有K线上拖动空白处则重画 |
| 右键 / Delete | 删除鼠标所在列的K线 |
| Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y） | 撤销 / 重做 |
| 工具栏 | 调整K线根数（5 到 60）、切换绿涨红跌或红涨绿跌、清空、导出 PNG |

价格轴固定为 0 到 100，纵轴刻度仅作位置参考。
